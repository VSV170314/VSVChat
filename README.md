# VSVChat

> Connect. Chat. Create.

VSVChat is a lightweight, real-time web chat platform inspired by the simplicity of Discord.

Users can create an account, chat in the public `GENERAL` channel, and create or join private chat rooms using a unique chat code and password.

---

## ✨ Features

- 🔐 Username + password authentication
- 👤 Account creation and login
- 💬 Real-time messaging
- 🌐 Public `GENERAL` chat
- 🏠 Create custom chat rooms
- 🔑 Password-protected chat rooms
- 🔢 Unique 6-character chat codes
- 🚪 Join chats using a code + password
- 💾 Persistent joined chats
- 🔄 Real-time message updates
- 🚪 Logout functionality
- 📱 Responsive design
- 💻 Works on desktop, tablet, and mobile browsers
- 🌌 Cyber-themed interface
